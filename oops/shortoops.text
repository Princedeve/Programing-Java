What are the four pillars of OOP?

The four pillars of Object-Oriented Programming are Encapsulation,
Inheritance, Polymorphism, and Abstraction. Encapsulation protects 
and bundles data, Inheritance provides code reuse through parent-child
relationships, Polymorphism allows the same interface or method name to
have different behavior, and Abstraction hides implementation details 
while exposing essential functionality.
